# 北辰微信登录接入

协议来源：[北辰平台文档](https://u.beichenwl.cn/doc.php)，协议查阅日期 2026-09-21。本页已同步当前实现；真实平台配置和扫码仍需目标环境验证。

## 平台协议

- 服务端 GET `https://u.beichenwl.cn/connect.php?act=login&appid=...&appkey=...&type=wx&redirect_uri=...` 获取 JSON `{code:0,type:'wx',url:'https://...'}`，浏览器只打开返回的 url。
- 用户授权后，平台跳回 redirect_uri，追加 `type=wx&code=...`。
- 服务端 GET 同一个 connect.php，传 `act=callback,appid,appkey,type=wx,code` 交换身份；成功响应必须为 `code:0,type:'wx',social_uid:'...'`。`code:2` 表示尚未完成登录。
- 文档没有承诺回传标准 OAuth state 参数，所以把随机状态放入本站回调路径 `/api/auth/wechat/callback/:state`，并与发起浏览器的 HttpOnly Cookie 绑定。
- 不向浏览器发送 appkey，不保存平台 access_token、性别、位置和 IP，也不根据昵称或邮箱合并账号。

## 产品行为

未登录用户通过微信登录，首次授权创建本地账号及零余额钱包。微信不提供邮箱，因此邮箱与密码允许为空，不生成虚假邮箱。生产启用 `REQUIRE_VERIFIED_EMAIL=true` 时，发起登录前须同意使用条款，首次登录后先补充并验证邮箱，再创建或加入情侣空间。`REGISTRATION_OPEN=false` 时拒绝创建新微信账号，已经绑定的账号仍可登录。

已有账号应先用原方式登录，再在账户区域绑定微信。绑定保留本地账号 ID、空间、积分、订单。微信已属于另一账号时拒绝绑定，不合并账号；目前不提供单独解绑入口，注销账号会删除其微信身份关联。

微信新用户可补充尚未占用的邮箱，用于验证及邮件提醒。补充邮箱不创建密码登录方式；密码找回仅适用于原本就有密码的账号，不能把微信身份转换为邮箱密码登录。原邮箱密码账号绑定微信后，仍可用邮箱恢复或修改密码。目前不提供直接更换已绑定邮箱的入口。

账号设置支持导出数据、关闭空间和注销。只有微信身份的账号关闭空间或注销前，须在最近 10 分钟内重新登录；已设置密码的账号需要输入密码。关闭空间保留双方账号，离开已关闭空间后可重新配对，具体退款和积分结算规则见 [设计文档](设计文档.md)。

## 接口契约

- `GET /api/bootstrap` 提供 `wechatEnabled,requireVerifiedEmail,registrationOpen`；`user.email` 可空，`user.wechatBound` 表示微信绑定，`user.hasPassword` 区分需要密码还是近期微信会话验证敏感操作。
- `POST /api/auth/wechat/start {intent:'login'|'bind',acceptTerms?}` → `{url:string}`；前端打开该地址。登录入口仅匿名使用，绑定要求已登录；启用验证门槛时登录请求须 `acceptTerms:true`。未配置返回 503。
- `GET /api/auth/wechat/callback/:state?type=wx&code=...`：处理并 303 跳回本站根路径 `/`。
- 回跳参数 `?wechat=logged_in`、`?wechat=bound` 或 `?wechat=error&reason=...`。错误 reason 使用固定枚举：`disabled,invalid_state,session_changed,cancelled,provider_error,identity_conflict`；前端映射友好提示并清理地址栏。已配对用户普通登录默认进入「约定」，绑定成功进入「我们 → 账号设置」；从邮件发起登录仍继续定位原内容。
- `POST /api/auth/email {email}`：仅给当前没有邮箱的账号补充邮箱；重复/占用冲突拒绝，不做账号合并。

## 数据与防护

身份表 `auth_identities` 按 `(provider,app_id,provider_uid)` 唯一，并约束一个用户在当前平台应用中最多绑定一个微信。状态表 `oauth_states` 保存状态摘要、浏览器随机凭证摘要、用途、发起账号与会话摘要、应用 ID、十分钟有效期、已消费时间。

状态在请求第三方前原子消费，失败需要重新发起。绑定回调必须仍是原来的有效会话；身份交换后，写入绑定前还会在数据库事务中重新校验会话，拒绝已退出或过期的授权。绑定与新会话创建、原会话废止一起提交。直接微信登录不会撤销该账号其他设备的会话。新微信账号并发登录通过身份锁与唯一索引防止重复账号；同一账号不能绑定两个不同微信。

第三方请求限时 10 秒，禁止 HTTP 重定向；返回给浏览器的授权地址只接受 `https://u.beichenwl.cn`，拒绝 URL 用户凭据和包含 AppKey 的地址。开启应用日志时，回调路径中的状态值和 URL 查询参数会隐藏。反向代理有独立的访问日志配置，上线时也应避免记录回调授权参数。

## 配置

生产环境在 `/admin` 后台填写并保存微信开关、App ID 和 AppKey。密钥在服务端加密保存，不写入 `production.env`。HTTPS、域名和回调反代由运营方自己的代理负责。

在北辰后台为应用启用微信方式，并登记实际网站域名。回调前缀为 `https://你的网站域名/api/auth/wechat/callback/`，末尾每次带不同随机状态。需确认平台允许该域名下的动态回调路径，且完整保留 redirect_uri。文档未写明是否要求完整回调白名单，正式接入时须实测。

本地自动化使用注入的模拟平台响应，不调用真实平台或微信。真实联调还需要有效的北辰应用凭据、平台域名配置和用户扫码授权。

修改后台设置后无需改环境文件；worker 会在下一轮读取最新配置。真实联调还需要有效的北辰应用凭据、外部反代提供的回调地址和用户扫码授权。补充邮箱和验证邮件也在 `/admin` 配置 SMTP 后生效。
